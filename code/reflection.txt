Unlike Assignment 02, where data lineage was implicit, this assignment gave us the experience of how important it is through copy-add-return function, which states that the function must perform: out = frame.copy(), add one column, and return out. Copying is essential because in the first attempt I had the impression that a step can mutate the frame, but the test for lineage makes sure that is not the case, not just the output. Graining was an essential concept in Assignment 04, since there were different graining in each data frame. The roster has a granularity where one row represents one person, but timesheet has a granularity of one row representing a person-who-worked-that-week. This meant that merge_employees should have merged the two data frames using a left join using employee_id as the key, which means that it keeps all the rows in the timesheet dataframe, including unmatched ones that will have NaN for the roster columns.It became much easier to understand how they work after comparing them. The add_gross_pay() in compute.py required a different approach using DataFrame.apply() and a lambda expression because it relied on two variables from the same row, hours_worked and hourly_rate_usd.
